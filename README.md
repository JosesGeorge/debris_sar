# Underwater Debris Detection System

React/Vite dashboard simulating a SONAR-equipped underwater drone that tracks and classifies marine debris. Detection records, telemetry, classification confidence, and the animated canvas SONAR field share the same simulated data flow.

## Run locally

```bash
npm install
npm run dev
```

Create a production build with `npm run build`.

The classifier and detections are simulated locally; no real-world machine-learning model or hardware integration is claimed.
